# AI 2D 에셋 제작과 교체 안내

이번 프로젝트는 임시 벡터 그래픽을 사용합니다. 아래 리소스를 따로 제작하면 시안의 분위기로 바꿀 수 있습니다. 숫자·카드 무늬·게임 UI 글자는 엔진에서 정확하게 표시하세요.

| 리소스 | 제작 기준 | 연결 위치 |
|---|---|---|
| 펍 배경 | 세로 1080×1920 이상, 따뜻한 조명, 글자 없는 그림 | `Table/Backdrop`에 TextureRect 추가 후 기존 그리기 스크립트 교체 |
| 테이블 | 인물·카드·숫자가 없는 초록 펠트와 나무 테두리 | `PlayArea/Felt`에 TextureRect 추가 후 기존 그리기 교체 |
| NPC 인물 | 투명 배경 PNG/WebP, 동일 인물의 기본·기쁨·불만 표정 | 각 `NpcSeat/Portrait.texture` |
| 카드 뒷면 | 세로 비율 약 0.70, 가장자리 여백, 문자 없는 장식 | `Card`에 TextureRect 추가, `card.gd`의 `_draw()` 교체 |
| 칩·장비 | 투명 배경, 일관된 광원과 크기 | 칩 지급 기능을 개발할 때 별도 씬으로 추가 |

인물 PNG를 넣으면 임시 실루엣은 자동으로 표시되지 않습니다. 기존 Portrait는 아이콘용 정사각형 프레임입니다. 상반신 인물을 사용할 때는 프레임을 늘리고 이름·카드 영역과 겹치지 않도록 씬을 조정하세요.

배경 프롬프트 예시:

> 성인 손님을 대상으로 하는 캐주얼 모바일 딜러 게임용 고급 펍 내부 배경. 따뜻한 호박색 조명, 어두운 목재, 차분한 분위기, 섬세한 2D 일러스트. 중앙에는 게임 UI를 배치할 여백. 인물, 카드, 칩, 숫자, 글자, 로고 없이. 세로 구도.

NPC 프롬프트 예시:

> 동일 캐릭터를 반복 사용할 모바일 게임용 성인 손님 상반신 일러스트. 정면에 가까운 시점, 따뜻한 왼쪽 조명, 선명한 윤곽, 친근하고 차분한 표정, 투명 배경. 숫자, 글자, 카드와 테이블 없이. 기준 이미지의 얼굴·헤어·의상을 유지.

카드 뒷면 프롬프트 예시:

> 모바일 카드 게임의 카드 뒷면 디자인. 짙은 버건디 바탕, 얇은 금색 테두리, 반복되는 작은 다이아몬드 장식, 중앙의 스페이드 장식, 대칭적인 세로 구도. 글자와 숫자 없이. 카드 외부는 투명 배경.

현재 UI는 시스템 한국어 폰트를 사용합니다. 출시판은 상업적 배포와 임베딩이 허용된 한국어 폰트 파일을 프로젝트에 포함하여 기기별 차이를 줄이세요. AI 서비스와 외부 이미지·폰트·효과음의 사용 조건도 기록해두세요.

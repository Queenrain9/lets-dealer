# LUCKY DEALER - 한 테이블, 한 판 기획서

**확정 기준:** 2026-09-29 / 단비의 1인 개발 / Godot 4.7.2 / GDScript / 2D 세로 화면 / Android 우선

**경험 목표:** 신입 딜러가 카드와 칩을 정확하고 빠르게 다루는 손맛을 만든다. NPC끼리 게임을 진행하며, 플레이어의 성과는 딜러 업무의 정확도와 속도로 평가한다.

**한 판 흐름:** 카드 배분 → NPC 진행 자동 연출 → 공용 카드 공개 → 승자 선택 → 지급액 구성과 칩 전달 → 팁·경험치 결과.

**첫 테이블:** 지민(왼쪽), 맥스(가운데), 소연(오른쪽). 배분 순서는 지민 → 맥스 → 소연을 2회 반복하여 각 2장, 총 6장이다. NPC는 각각 1,000칩을 내며 팟은 3,000칩이다. 플레이어의 팁·경험치는 테이블 칩과 별도로 관리한다.

**초기 시나리오:** 공용 카드 J♣ / 10♥ / 7♠ / A♠ / 2♦. 지민 Q♣·9♦, 맥스 10♣·8♦, 소연 A♥·K♣. 승자는 소연(에이스 원페어), 지급액은 3,000칩. 초기판은 동일 참가액의 고정 시나리오로 시작하고, 무승부·올인·사이드 팟은 후속 작업에서 별도로 검증한다.

**조작:** PC는 왼쪽 마우스로, 모바일은 손가락 하나로 카드를 잡고 강조된 좌석의 카드 영역 안에 놓는다. 다른 좌석에 놓으면 실수 1회이며 카드가 돌아온다. 빈 테이블에 놓거나 입력이 취소되면 카드가 돌아오고 실수는 늘지 않는다. 이후 승자는 좌석 탭으로 선택하고, 100/500/1,000칩 버튼으로 액수를 구성한 뒤 선택한 승자에게 전달한다.

**성공·실패:** 첫 유효한 카드 집기부터 60초 안에 배분·승자 선택·정확한 지급을 모두 마치면 한 판 성공. 실수 3회 또는 시간 0초면 실패. 일시정지와 앱 포커스 이탈은 시간을 멈추고 잡은 카드를 돌려놓는다. 계속하기는 사용자가 직접 누른다. 재시작은 시간·배분·실수를 초기화한다.

**평가:** 정확도 = 성공한 업무 / (성공한 업무 + 실수). 무실수 완료 시 PERFECT. 팁과 경험치는 업무 평가에서 지급하며 환전·현금성 보상은 연결하지 않는다. 세부 성장 수치는 후속 기능 개발 시 결정한다.

**이번 구현 - 카드 배분 훈련:** 총 6장 배분, 60초, 잘못된 좌석 판정, 입력 취소, 마우스·터치, 일시정지, 재시작, 훈련 결과를 구현한다. 6장을 배분하면 ‘배분 훈련 완료’로 표시한다. 승자 계산·칩 지급·성장·저장·광고·결제는 이번 구현에 포함하지 않는다.

**완료 확인:** 올바른 순서로 6장 배분 / 오배분 3회 실패 / 시간 초과 실패 / 빈 곳에 놓기 무벌점 / 두 번째 손가락으로 카드 탈취 불가 / 중단·재시작 후 중복 배분 없음. 화면은 임시 벡터 그래픽으로 구성하며 배경·NPC·카드 뒷면을 AI 제작 에셋으로 교체할 수 있게 나눈다.

# Stage 5 — Tutorial Removal / Game Feel Pass

Goal: make the live shift feel like a game table rather than a continuously guided tutorial.

Runtime changes:
- Removed permanent dealer toolbar and tutorial-style instruction copy.
- Hid permanent NPC personality labels; personality remains behavioral.
- Hid the developer TABLE LOG during gameplay.
- Reduced top status to terse game-state information.
- Converted chip-change requests into seat-relative bubbles.
- Kept table-first interaction: deck, board, pot, request bubble, and seats.
- Replaced text prompts with a single subtle scale nudge on relevant table objects.
- FLOOR stays hidden until an actual delayed/urgent duty appears.
- Harmless taps are mostly no-ops rather than training-style mistakes.
- Wrong payout and meaningful procedural errors still affect performance.

The live NPC, overlapping-duty, FLOW, dynamic request, and personality systems from prior stages remain active.
